
# Real-Time Image Captioning for Visually Impaired Users

## Overview
This project aims to assist visually impaired users by generating natural-language descriptions of images and converting the generated captions into speech.

## Objectives
- Generate meaningful captions for images using deep learning.
- Convert generated captions into speech for audio-based assistance.
- Provide a simple interface for users to upload or capture images.

## Technologies
- Python
- Streamlit
- PyTorch
- Hugging Face Transformers
- BLIP Image Captioning Model
- Pillow
- OpenCV
- pyttsx3

## Features
- Image upload and image capture.
- Automatic image caption generation.
- Text-to-speech output.
- Caption history.

## How It Works
1. The user uploads or captures an image.
2. The image captioning model analyzes the image.
3. The application generates a natural-language caption.
4. The caption is converted into speech using text-to-speech functionality.

Deep Learning Mini Project

# Customer Review Sentiment Analyzer

## Overview
The Customer Review Sentiment Analyzer is a Python-based project designed to process customer reviews and prepare text data for sentiment analysis. It supports multiple input formats and helps organize review data for further analysis.

## Objectives
- Read customer reviews from CSV, JSON, and TXT files.
- Clean and preprocess review text.
- Prepare cleaned data for sentiment analysis.
- Support further analysis and visualization of customer feedback.

## Technologies Used
- Python
- Regular Expressions (`re`)
- JSON
- CSV
- Pandas (optional)
- Emoji (optional)

## Features
- Supports CSV, JSON, and TXT input files.
- Text-cleaning and preprocessing functionality.
- Optional Pandas integration.
- Optional emoji processing support.
- Generates cleaned review data for downstream sentiment analysis.

## Project Workflow
1. Read customer review data from the supported file formats.
2. Clean and preprocess the review text.
3. Prepare the processed data for the sentiment analysis module.
4. Use the cleaned data for further analysis and visualization.
